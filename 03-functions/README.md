# 03 — Functions

Refactoring previous exercises into functions with input validation, plus a small Euclidean-distance project.

## Files

| File | Description | Concepts |
|---|---|---|
| `calculator_functions.py` | Calculator built with small operator functions | Functions, try/except |

| `validate_contact.py` | Minimal phone/email validation | String methods |
