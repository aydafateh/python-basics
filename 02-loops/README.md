# 02 — Loops

Exercises focused on `for` and `while` loops, plus a loop-based ATM and a second tic-tac-toe.

## Files

| File | Description | Concepts |
|---|---|---|
| `multiplication_table.py` | Print multiplication table of a number | for, range |
| `prime_numbers_between.py` | Find all primes between two numbers | for, break, sqrt |
| `reverse_number.py` | Reverse the digits of a number | while, modulo |
| `simple_atm.py` | Menu-driven ATM (balance, withdraw, deposit) | while, conditions |
| `tic_tac_toe_for_loop.py` | Tic-tac-toe using loops and a board list | while, for, lists |

## Notes

`tic_tac_toe_for_loop.py` is a step up from `01/tic_tac_toe.py` — it uses a `board` list and a main loop instead of repeating the same block three times.
