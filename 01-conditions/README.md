# 01 — Basics & Data Types

First exercises covering input/output, type conversion, validation, and basic data structures (dict, tuple, list, set).

## Files

| File | Description | Concepts |
|---|---|---|
| `age_calculator.py` | Calculate age from birth date and today's date | Input, split, int, conditions |
| `age_category.py` | Classify age into baby/child/teen/young/adult/old | Conditions, comparisons |
| `armstrong_number.py` | Check if a number is an Armstrong number | Loops, strings, math |
| `blood_test.py` | Interpret CBC blood test values | Conditions, type conversion |
| `factorial_with_error_handling.py` | Factorial with try/except | Loops, try/except |
| `float_converter.py` | Convert a float string to various types | Strings, tuple, list, set |
| `tic_tac_toe.py` | First (procedural) version of tic-tac-toe | Conditions, strings |
| `user_info_dict.py` | Validate user info and store in a dictionary | Dict, validation, conditions |

## Notes

These files use a lot of nested `if/else`. Later folders (03) refactor the same logic into functions.
