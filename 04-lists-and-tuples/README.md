# 04 — Lists & Sorting

Small exercises using lists, sorting, and simple matrix handling.

## Files

| File | Description | Concepts |
|---|---|---|
| `largest_number.py` | Arrange digits of a number to make the largest number | list, sort, join |
| `longest_sequence.py` | Return the largest of three numbers | list, sort |
| `matrix_printer.py` | Print rows of a matrix from user input | list, append, print |

## Notes

`longest_sequence.py` currently sorts strings, not numbers. If you enter `9`, `10`, `2`, it will pick `9` (string sort). Consider converting to `int` before sorting.
